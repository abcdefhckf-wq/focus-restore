視線中斷偵測與焦點還原用筆電鏡頭注意你的視線。你轉頭、離開座位時，它記住最後讀到的句子；你回來時，那一句會亮起一個圓形高光。

為什麼被打斷後很難接回去？

閱讀時，眼睛並不是平滑地滑過一行字，而是一個詞一個詞地跳動，每次只停留不到半秒。大腦會把這些片段拼起來，讓我們以為自己是連續在讀。所以一旦電話響了、有人叫你，再回到畫面時，那條拼接的線就斷了。

你得重新掃過整段，才找得到剛才停在哪一句。段落越長、文字越密，花的時間就越多。

你離開了畫面…
高光會在你按空白鍵後 3 秒內慢慢淡掉。
運作方式

三件事，全自動

1　偵測離開

知道你真的離開了

鏡頭追蹤臉、頭的方向和眼睛。轉頭、低頭看手機、離開座位、閉眼，都會被判定為中斷。瞄一眼旁邊或眨眼不會。

2　記住位置

記下最後讀到的句子

系統取離開前那段時間的注視點，對到頁面上的文字。視線落在行與行的空白處時，會找最近的那一句。

3　回來高光

回來時那一句亮起來

臉回到鏡頭前，那一句會出現約 4 公分的圓形高光，中心比外圈更亮，捲動頁面時也會跟著文字走。按空白鍵讓它淡掉。

功能

讀網頁、讀論文都用得上

一般網頁文章

新聞、部落格、線上教材，在分頁裡按一下「在此分頁啟動」就能用。

PDF 與本機論文

內建 PDF 閱讀器，電腦裡的 PDF 拖進去就能讀，也可以在 PDF 連結上按右鍵直接開啟。

校準一次，到處沿用

校準結果會保存下來。換分頁、換一份 PDF、隔天重開瀏覽器，都不必重新校準。

不會被眨眼、瞄一眼觸發

頭轉開約半秒就算離開，只有眼睛飄走要持續一段時間才算。眨眼的畫面會被過濾掉。

切走分頁就關鏡頭

分頁切到背景時鏡頭自動停止，切回來再自動恢復，不會在背景一直開著。

依你的筆電自動調整

校準時會量測這台電腦的鏡頭雜訊和運算速度，自動調整判斷參數。電腦慢一點也能正常使用。

可選：AI 語意定位

填入自己的 OpenAI 或 Anthropic API Key 後，會請 AI 從附近的文字挑出最可能的那一句，避開按鈕、頁碼這類非正文。

8 種語言、可自訂高光

繁中、簡中、英、日、韓、西、法、德全部內建。高光的大小、顏色、透明度都能調整。

隱私

鏡頭畫面不會離開你的電腦

臉部與視線偵測全部在瀏覽器裡完成，用的是擴充功能自帶的 WebGazer 與 MediaPipe，不需要連到任何伺服器。

沒開 AI 定位時

  • 不上傳任何影像、視線資料或網頁內容。
  • 校準結果和設定只存在這台電腦的瀏覽器裡。
  • 切走分頁時鏡頭會關閉。

開了 AI 定位時

  • 只有你視線附近的那幾段網頁文字，會送到你自己設定的 AI 服務。
  • 鏡頭影像仍然不會送出。
  • API Key 只存在你的瀏覽器裡。閱讀機密文件時，建議把 AI 定位關掉。
使用教學

從安裝到第一次用，大約 5 分鐘

需要 Chrome（或 Edge 等 Chromium 瀏覽器）和一台有鏡頭的電腦。第一次打開設定面板時，會先請你選語言，再帶你看一遍各個功能的位置。

  1. 安裝擴充功能

    1. 把下載的 zip 解壓縮。
    2. 在網址列輸入 chrome://extensions，打開右上角的「開發人員模式」。
    3. 按「載入未封裝項目」，選擇直接包含 manifest.json 的那一層資料夾。選到外層資料夾會出現「資訊清單檔案遺失」。
    4. 按工具列的拼圖圖示，把「視線中斷偵測與焦點還原」釘選出來，之後比較好找。

  2. 在文章頁面啟動

    打開想讀的網頁，點擴充功能圖示，按「在此分頁啟動」，瀏覽器詢問時允許使用鏡頭。

  3. 完成校準

    畫面會出現校準流程，可能是跟著圓點移動的進度條，也可能是 9 個點各點三下，最後幾個驗證點只要看著、不用點。完成後會顯示預估誤差。下次啟動時若條件相同，會直接沿用，不再出現校準畫面。

  4. 照常閱讀，離開也沒關係

    讀到一半去看手機、跟人說話、起身倒水都可以。回到電腦前，最後讀的句子會出現圓形高光。找到位置後按 Space，高光會在 3 秒內淡掉。

  5. 讀 PDF 或論文

    Chrome 內建的 PDF 檢視器不允許擴充功能讀取內容，所以請用擴充功能自己的閱讀器：

    • 設定面板按「選擇本機 PDF…」，或把 PDF 直接拖進閱讀器。
    • 正在看線上 PDF 時，面板會出現「用外掛閱讀器開啟目前的 PDF」。
    • 在 PDF 連結上按右鍵，選「用視線還原閱讀器開啟此 PDF」。

    開啟後按閱讀器工具列的「開始追蹤」。本機的 HTML 論文（file:// 開頭）則要到擴充功能的「詳細資料」打開「允許存取檔案網址」。

  6. 依習慣調整

    設定面板可以調整高光的直徑、顏色和透明度、視線消失幾秒算離開、校準方式，以及是否在切換到其他視窗時也暫停。準確度變差時，隨時按「重新校準」。

讓偵測更準的小技巧

  • 讓臉部光線充足，避免背後有窗戶或燈直接照向鏡頭。
  • 用平常閱讀的坐姿和距離校準。之後坐姿差很多時，重新校準一次會比較準。
  • 校準時頭盡量不動，只用眼睛跟著圓點。
  • 戴不戴眼鏡最好用當時的狀態校準，鏡片反光嚴重時可以把螢幕亮度調低一點。
常見問題

你可能會想問

需要一直連網嗎？

不需要。偵測與高光都在你的電腦上完成，只有開啟 AI 語意定位時，才會連到你設定的 AI 服務。

AI 語意定位要付費嗎？

這個功能用的是你自己的 API Key，費用依你使用的服務計算。不開也能正常使用，系統會改用最靠近視線的那一句。

為什麼高光沒有出現？

可能是離開的時間太短而沒被判定為中斷、頁面是圖片沒有文字可以對應，或視線離文字太遠而找不到句子。畫面上若出現「無法定位先前的閱讀位置」，可以試著重新校準。

掃描的 PDF 可以用嗎？

不行。掃描檔裡的字其實是圖片，沒有可以對應的文字層，閱讀器開啟時會提示。

換一份 PDF 或換分頁，要重新校準嗎？

不用。只要眼睛到螢幕的距離設定、角度設定和視窗大小差不多，就會沿用上次的校準。換了一台螢幕或視窗大小差很多時，才會請你重新校準。

鏡頭燈一直亮著，會一直錄影嗎？

不會錄影，也不保存畫面。鏡頭只在你啟動的分頁、而且分頁在前景時開著，按「停止」或切走分頁就會關閉。

不小心選錯語言，怎麼改？

設定面板最下方的「語言」可以隨時切換，切換後立即生效。
